tidymodels



install.packages("tidymodels")
library(tidymodels)


  • A collection of R packages for modeling (e.g., regression, machine learning)
  • Uses tidyverse principles (good for data wrangling and visualization)
  • Sets up workflows that are reproducible

tidymodels is a collection of many packages

There are ~8 core packages in tidymodels. We’ll focus on:


  • rsample - Splits data into training and testing sets
  • recipes - Preprocesses data
  • parsnip - Specifies models
  • broom - Converts model objects into tidy datasets
  • yardstick - Assesses model performance

The Jenkins equation form

\[ \ln(bm) = \beta_0 + \beta_1 \ln(dbh) \]

or equivalently, on the original scale:

\[ bm = e^{\beta_0 + \beta_1 \ln(dbh)} = e^{\beta_0} \cdot dbh^{\beta_1} \]

  • \(bm\) = total aboveground dry biomass (kg)
  • \(dbh\) = diameter at breast height (cm)
  • \(\beta_0, \beta_1\) = coefficients, one pair per species group
  • Linear on the log-log scale
  • We can use linear_reg()

broom: turns model objects into tidy datasets

  • Model objects from base R (e.g., lm()) store results in nested lists. These are awkward to work with.
  • broom converts model onject output into tibbles, so you can use the tidyverse.
  • Three key functions:
    • tidy() - Extracts model coefficients and related statistics
    • glance() - Provides overall model fit statistics
    • augment() - Adds predictions and residuals to the original data

Random forests

  • First, take several small samples of the data
  • Any observations that aren’t taken are called “out-of-bag” samples
  • Build a set of regression trees on the sampled data and calculate mean square error

Variable importance in random forests

  • If the percent increase in MSE after removing the variable is large, it’s an important variable!
  • If the percent increase in MSE is small, it’s less important

Key arguments in rand_forest()


Argument Meaning Value
trees Number of trees in the forest e.g., 500
mtry Predictors considered at each split 1 or 2 (DBH or species group)
min_n Minimum observations to split a node e.g., 5

How to compare models?

Metric Measures
RMSE (kg) Typical error
MAE (kg) Mean absolute error
Bias (%) Systematic over- or under-prediction


  • Compute metrics on the original (kg) scale
  • Use the held-out (test) data

The yardstick package

  • Provides metric functions, e.g., rmse(), mae(), rsq()
  • metric_set() bundles all metrics using a single function
  • Outputs a dataset (i.e., a “tidy tibble”)
# Get one metric
rmse(test_pred, 
     truth = bm_kg,
     estimate = rf_kg)

# Get a bundle of metrics
biomass_metrics <- metric_set(rmse, mae, bias)
